# Finance Portfolio

A full-stack platform for real-time international market tracking and personal
investment portfolio management — with AI-generated company scorecards that
can run entirely on your own hardware.

- **Backend**: Python · FastAPI · SQLAlchemy (SQLite) · yfinance · APScheduler · Web Push (VAPID)
- **Frontend**: Next.js 16 (App Router) · React 19 · TailwindCSS 4 · Framer Motion · Recharts · Axios
- **AI analysis**: pluggable provider routing — run fully local (Ollama, LM Studio) or point at a cloud API

---

## Features

- Live market dashboard (SSE) with major indices and top movers
- Global asset search (stocks, ETFs, crypto, commodities, mutual funds) via Yahoo Finance
- Portfolio tracking in EUR with automatic currency conversion, buy/sell operations, and P&L
- MIFID-style investor profile test that drives target asset allocation
- Technical alerts (Golden Cross, RSI, MACD, ...) with Web Push notifications
- AI company scorecards (0-100 score, bull/bear case, key stats) generated by a local or cloud LLM of your choice

## Quick start (Docker)

```bash
docker compose up --build
```

Backend: http://localhost:8000/docs · Frontend: http://localhost:3000

By default the backend expects an [Ollama](https://ollama.com) instance
reachable at `http://localhost:11434` on the host (`OLLAMA_URL` in
`docker-compose.yml`). Install Ollama, run `ollama pull llama3.1`, and the AI
scorecard feature works with zero API keys and no data leaving your machine.

## Quick start (manual)

### Requirements

| Tool | Minimum version |
|------|------------------|
| Python | 3.11+ |
| Node.js | 20+ |

### Backend

```bash
cd backend
python3 -m venv ../.venv
source ../.venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # edit if needed
uvicorn main:app --reload --port 8000
```

Check http://localhost:8000/health → `{"status":"ok",...}`

### Frontend

```bash
cd frontend
pnpm install
echo "NEXT_PUBLIC_API_URL=http://localhost:8000/api" > .env.local
pnpm dev
```

Open http://localhost:3000

## AI provider configuration

Set `LLM_PROVIDER` in `backend/.env` to any of:

| Provider | `LLM_PROVIDER` | Where it runs | Requires an API key? |
|---|---|---|---|
| **Ollama** (default) | `ollama` | 100% local | No |
| LM Studio | `lmstudio` | 100% local | No |
| Generic OpenAI-compatible | `openai_compatible` | Local (vLLM, LocalAI) or cloud (OpenAI, OpenRouter, Groq, Together) | Depends on the endpoint |
| Anthropic Claude | `anthropic` | Cloud | Yes |

Each provider reads its own settings from `.env` (URL, model name, API key
where relevant) — see `backend/.env.example` for the full list. If the
configured provider is unreachable or misconfigured, the analysis endpoint
falls back to a deterministic offline scorecard instead of failing.

Adding a new provider is a single file — see `CONTRIBUTING.md`.


## Notes

- The SQLite database is created and seeded automatically on first run
  (~660 assets + 8 model portfolios). It is not versioned; delete
  `backend/finance_portfolio.db` to start fresh.
- Never commit `.env`, `.env.local`, or `vapid_private.pem` — already covered
  by `.gitignore`. Use `.env.example` as the template.
